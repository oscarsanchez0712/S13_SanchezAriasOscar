# Dashboard Hotel Valle Real (Angular Routing)

Sistema de Hotel: habitaciones, tipos, huéspedes y reservas.

## Ejecutar
```bash
npm install
ng serve
```
Abrir http://localhost:4200

## Rutas (app.routes.ts)
- `/inicio` · `/habitaciones` · `/huespedes` · `/reservas`
- `**` → página 404 (NoEncontradoComponent)
